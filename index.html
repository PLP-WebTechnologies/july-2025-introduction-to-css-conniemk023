Welcome to the CSS Box Model Demo

This page demonstrates how HTML and CSS work together to create a structured and styled layout.

Understanding the Box Model

Every element on a web page is a rectangular box. The box model defines how padding, borders, and margins are added to the content of this box.

Key CSS Properties

The `styles.css` file uses different selectors to apply styles to this page. Below is a list of some of the properties in action.

  • `padding`: Inner space around the content.
  • `border`: A line around the padding.
  • `margin`: Outer space between elements.
  • `color`: Changes the text color.
  • `background-color`: Fills the background of an element.
